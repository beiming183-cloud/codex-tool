# Codex 工具箱

面向 Windows 的 Codex 连接检查与额度工具。打开即可发现正在运行的 Codex，不要求固定 IP、双开或手动寻找安装位置。

[下载 Windows 版](https://github.com/beiming183-cloud/codex-tool/releases/latest) · [更新记录](CHANGELOG.md) · [使用细节](docs/TECHNICAL.md) · [反馈问题](https://github.com/beiming183-cloud/codex-tool/issues)

## 开始使用

1. 在 Releases 下载 `CodexToolbox-版本号-win-x64.zip`，解压并打开 `Codex工具箱.exe`。
2. 先打开并登录 Codex，工具箱会自动发现窗口、代理与已观测连接。
3. 首页看线路，额度页添加浮层；其他功能按需展开即可。

便携版自带 .NET 运行时，无需安装 Python、Node 或额外模块。适用于 Windows 10/11 x64，系统需保留自带 Windows PowerShell。

## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| 自动线路检查 | 按每个 Codex 分别观察请求、代理出口采样和最近的 IP 变化 |
| 额度浮层 | 自动寻找对应登录目录；支持连接的窗口直接添加，其他窗口使用独立浮窗 |
| 校园网保护 | 结合当前网络与教育域特征识别，允许自定义和确认；启用时需要管理员授权 |
| 诊断工具 | 检查 Clash / Mihomo 状态、应用连接和公网出口 |
| 自适应界面 | 75%–150% 缩放，窄窗口自动收起侧栏，卡片重新排版 |
| 版本更新 | 启动时检查本仓库 Releases，有新版在窗口顶部提示；也可手动检查 |

不同账号可以使用不同 IP。代理采样不代表每条模型请求；证据不足时保持“尚未确认”，不会用绿色状态作保证。

## 内置更新

打开后会自动检查正式版本，每六小时缓存一次检查结果；“设置 → 版本与更新”可随时手动检查或关闭自动检查。

有新版时，顶部提供“下载更新”“说明”“稍后”。下载可取消，程序会检查发布地址、文件大小、SHA-256 和版本，再准备重启替换；配置与上一版副本保存在本机。目录不可写时会提示移动工具箱，不自动申请额外管理员权限。首次使用 2.3 或更早的版本，需要从 Releases 手动下载一次 2.4 或更新版本。

网络错误、文件不完整或校验不符都不会替换当前版本。更新信息来自本仓库，不需要登录 GitHub；下载使用 Windows 手动系统代理或本机网络，不轮换账号的专用代理。PAC-only、代理客户端尚未就绪等环境可能需要手动下载。

## 配置与数据

- 发布包与仓库不包含个人配置、登录文件、节点密钥或运行日志。
- 默认配置位于 `%LOCALAPPDATA%\CodexToolbox`；支持 `--data-dir`，也支持在界面导入/导出配置。
- 额度只读取已有登录状态中的 access_token，不刷新 refresh_token，不修改 Codex 登录。接口变动或登录过期会提示重试。
- 导出的配置会移除接口密钥、登录目录与本机脚本集成；仍可能包含代理地址、IP 和网络名称，分享前请检查。
- 更新检查只访问 GitHub 版本接口，不上传登录信息、线路历史或个人设置。

## 构建与发布

需要 Windows 和 .NET 8 SDK：

```powershell
.\build.ps1
```

脚本编译自包含 x64 EXE、执行离线自检、收集运行时许可，并生成便携包、源码包和 `SHA256SUMS.txt`，输出在 `dist/release/版本号/`。

维护者发布新版时，修改项目版本与更新记录，提交后推送对应 `v版本号` 标签。GitHub Actions 会构建、检查版本、运行自检并创建 Release。已发布的资产不会被工作流覆盖。应用读取最新的非草稿、非预发布版本，只接受本项目规范命名的 Windows 包。

## 验证与限制

已在本机 Windows 150% 显示缩放下验证默认/小窗口/最大化、75%–150% 应用缩放、两账号发现和四项诊断。60 项离线回归覆盖配置、校园规则、线路归属、版本比较、发布信息校验和更新路径约束。

自动更新的实际二进制替换与失败回退尚需完整进程验收；未把元数据测试当作重启流程已经验证。完整校园网 SYSTEM 保护安装/卸载与真实学校网络切换、其他显示器 DPI、触摸设备和其他人的账号也尚未完整实机验证。校园识别是特征判断，不能保证识别所有学校。

`qa/` 中的原生界面脚本面向开发测试：需传入明确的测试进程及证据目录，部分脚本需要已运行的 Codex、Clash 与已有浮层。请使用隔离配置，避免对正在编辑的窗口运行。
